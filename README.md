Python Sales Tracker

A beginner-friendly Python project to record sales and generate a simple sales summary.

Features

- Store customer and product details
- Calculate total sales using price and quantity
- Calculate total revenue
- Count total items sold
- Calculate average sale value
- Identify the highest sale

Technologies Used

- Python
- Lists and dictionaries
- Loops and conditional logic
- Basic calculations

How to Run

1. Install Python 3.

2. Download or clone this repository.

3. Open a terminal in the project folder.

4. Run:
   
   "python sales_automation.py"

Project Purpose

This project was created to practise Python programming and apply basic programming concepts to a sales-tracking task.
